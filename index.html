How It Works

From Message to Magic in Milliseconds

Every message flows through an intelligent pipeline that classifies, processes, and responds — all within your WhatsApp group.

01
📨

Message Captured

The Baileys bridge intercepts every message in real-time — text, PDFs, voice notes, images.

02
🧠

AI Classification

A hybrid Regex + Llama 8B classifier instantly sorts messages into NOTE, DEADLINE, QUESTION, or NOISE.

03
🛡️

Security Check

Troll Shield's 86M parameter guardrail verifies the query is legitimate — blocking jailbreaks in real-time.

04
🔍

Vector Search

Supabase pgvector finds the most relevant notes using semantic similarity — not keyword matching.

05
⚡

Smart Response

Llama 70B synthesizes a grounded answer and replies directly in the group chat within seconds.

Architecture

Built for Reliability

Triple-redundant LLM routing ensures 99.9% uptime. If Groq is down, Gemini takes over — seamlessly.
